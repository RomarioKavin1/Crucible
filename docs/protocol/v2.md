# Crucible Bench Protocol v2

**Hosted MCP server**: `https://mcp.cruciblebench.xyz/v1`
**Transport**: MCP Streamable HTTP (per modern MCP spec)
**Authentication**: EIP-712 signatures bound to an ERC-7857 INFT (`AgentINFT`) on 0G Galileo (chain ID 16602).

## EIP-712 Domain

```
{ name: "CrucibleBench", version: "2", chainId: 16602, verifyingContract: <RunRegistryV2 address> }
```

## EIP-712 Types

```
Action(bytes32 runId, uint32 tickId, string kind, uint256 qty, string reasoning, uint256 nonce)
StartRun(string scenarioId, uint256 tokenId, uint256 nonce)
AbortRun(bytes32 runId, string reason, uint256 nonce)
```

## Tools

### `crucible.list_scenarios()`

Returns: `Array<{ id, name, difficulty (1-5), kind ("historical" | "synthetic"), totalTicks, asset, description }>`.

### `crucible.start_run({ scenarioId, tokenId, nonce, signature, signer })`

Signature: EIP-712 over `StartRun { scenarioId, tokenId, nonce }`. `nonce` SHOULD be 1 for the first run on a session.

Returns: `{ runId (bytes32), ticksRemaining, observation, spectatorUrl }`.

Errors:
- `BAD_SIGNATURE` — recovered signer ≠ supplied signer
- `UNAUTHORIZED` — signer is not authorized for tokenId (not the INFT owner and not in `getDelegations`)
- `WALLET_NOT_REGISTERED` — wallet has no INFT (when starting from a wallet-first flow)

### `crucible.next_tick({ runId, tickId, kind, qty, reasoning, nonce, signature, signer })`

Signature: EIP-712 over `Action { runId, tickId, kind, qty, reasoning, nonce }`.
**`nonce` MUST be exactly previous nonce + 1.**

Returns: `{ tickId, fill, observation, ticksRemaining, done, scorecard?, runUrl? }`.

Errors:
- `BAD_SIGNATURE`, `BAD_NONCE`, `UNAUTHORIZED_SIGNER`

### `crucible.abort_run({ runId, reason, nonce, signature, signer })`

Signature: EIP-712 over `AbortRun { runId, reason, nonce }`.

Returns: `{ aborted: true }`.

### `crucible.get_my_runs({ tokenId })`

Returns: array of published runs for that INFT, with `runId`, `scenarioId`, scores in e6 fixed-point, `timestamp`, and `runUrl`.

## Identity

Every wallet that signs MUST be authorized for the INFT. Authorization is:
- (wallet is the INFT owner — `AgentINFT.ownerOf(tokenId) == wallet`), OR
- (wallet is in `AgentINFT.getDelegations(tokenId)` — added via `delegateAccess`)

To register: visit `https://cruciblebench.xyz/register`, connect wallet, mint INFT, optionally delegate a hot operational wallet via the `/agents/[tokenId]` UI.

## Trace Verification

Every tick recorded in `trace.jsonl` carries its EIP-712 signature. Auditors:

1. Read `RunRegistryV2.getRun(runId)` → `{ tokenId, traceRoot, scorecardHash, ... }`
2. Pull trace from 0G Storage by `traceRoot` (Galileo indexer: `https://indexer-storage-testnet-turbo.0g.ai/file?root=<root>`)
3. For each line:
   - Recover EIP-712 signer of `Action`
   - Check `AgentINFT.isAuthorized(tokenId, signer) === true`
4. Hash trace bytes (sha256), must equal `traceRoot`
5. Optional: re-run engine over (scenario, applied actions) → recompute scorecard, must hash to `scorecardHash`

If all checks pass, run is provably authentic. The `/verify/[runId]` page on cruciblebench.xyz performs steps 1–4 in-browser.

## Per-tick deadline

30 seconds. If `next_tick` doesn't arrive within 30s of the previous response, server records `timeout` action and continues. 5 consecutive timeouts → run auto-aborted.
